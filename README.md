No. 1: Calculating Distance Between Two Points Using Math and I/O Libraries

Estimated Time: 20 minutes

Goal: Create a program that calculates the distance between two points using a math library. You will use the distance formula and built-in functions like sqrt() and pow().

Role: You are a beginner programmer learning how to solve math problems using code.

Audience: The user of your program. Your prompts should be clear so users know what to input.

Situation: You are given two points (x1, y1) and (x2, y2) on a 2D plane. Your program must calculate the distance between them using the Euclidean distance formula.

Performance and Purpose

You will write and run a program that applies math functions to solve a real-world problem. The purpose is to practice using libraries, user input, and formulas in programming.

Reflection and Evaluation

After completing your program, include your reflection directly in your source code as comments, placed either before or after your code.

Your reflection should answer the following question in 2–3 sentences:

Why is using a library more practical than writing all calculations from scratch? Explain briefly using your activity as an example.

How did the math library help simplify your program?
What functions were easier to use because of the library?
